## 📌 About the Project

**Smart BMI Calculator** is a beginner-friendly Python application that calculates a person's Body Mass Index (BMI) based on their weight and height.

The program uses the standard BMI formula to calculate the BMI value, classifies the result into different weight categories, and provides basic health suggestions based on the calculated result.

This project demonstrates the practical implementation of Python functions, conditional statements, mathematical calculations, and modular programming.

---

## ✨ Features

- 🧮 **BMI Calculation:** Calculates Body Mass Index using weight and height.
- 📊 **BMI Classification:** Identifies the user's BMI category.
- 💡 **Health Suggestions:** Provides basic suggestions based on the calculated BMI.
- 🧩 **Modular Programming:** Uses separate functions to organize the program.
- 🖥️ **Command-Line Interface:** Simple and easy-to-use terminal interaction.
- ⚡ **Instant Results:** Displays BMI, category, and suggestions immediately.

---

## 📊 BMI Categories

The calculator classifies BMI values using the following standard adult BMI ranges:

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obese |

*Note: These are general adult BMI screening categories, not a complete assessment of an individual's health.*

---

## 🧮 Formula Used

Body Mass Index is calculated using:

```text
BMI = Weight (kg) / Height (m)²
```

Where:
- **Weight:** Body weight measured in kilograms.
- **Height:** Height measured in meters.
- **BMI:** Calculated Body Mass Index value.

---

## ⚙️ How It Works

The application follows a simple execution flow:

1. The user enters their weight in kilograms.
2. The user enters their height in meters.
3. The program calculates BMI using the standard formula.
4. Conditional statements determine the appropriate BMI category.
5. A health suggestion is selected based on the category.
6. The program displays the BMI value, category, and suggestion.
