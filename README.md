# 🧮 Smart BMI Calculator

## 📌 Description

This project is a simple **Python-based BMI (Body Mass Index) Calculator** that evaluates a user’s health status based on weight and height inputs.

The program calculates BMI using the standard formula, classifies it into appropriate health categories, and provides personalized health suggestions.
It is beginner-friendly and demonstrates the use of functions, conditional statements, and structured programming in Python.

---

## 🚀 Features

* ✅ Calculates Body Mass Index (BMI)
* 📊 Classifies BMI into:

  * Underweight
  * Normal weight
  * Overweight
  * Obese
* 💡 Provides personalized health suggestions
* 🧩 Uses modular functions for clean and organized code
* 🖥️ Simple command-line interface

---

## 🧮 Formula Used

BMI is calculated using:

```id="h8k2pl"
BMI = Weight (kg) / Height² (m²)
```

---

## 🛠️ Technologies Used

* Python 3
* Built-in functions
* Conditional statements
* Modular programming

---

## ⚙️ How It Works

* User enters weight (in kilograms) and height (in meters)
* Program calculates BMI using the formula
* Based on BMI value, it determines the health category
* Displays result along with health suggestions

## 🖥️ Example

